Veganism is against animal USE

Description

Veganism is against animal use REGARDLESS of whether the animal has been abused or not. By framing veganism as the opposition to abuse, cruelty, harm, you are essentially weakening the vegan message, turning an abolitionist message into a welfarist one.

"Veganism is the doctrine that man should live without exploiting (using) animals." - Leslie Cross
